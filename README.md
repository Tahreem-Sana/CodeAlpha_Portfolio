# ✨ Personal Portfolio Website

A modern, responsive personal portfolio website built to showcase my skills, projects, experience, and learning journey as a Frontend Developer during my CodeAlpha internship.

## 📌 About The Project

This portfolio serves as my professional online presence, highlighting my frontend development skills, practical projects, and continuous learning journey. It is designed with a clean user interface, organized sections, and a responsive layout for different screen sizes.

## 🚀 Features

- **Home / Hero Section** — Introduction, developer role, and call-to-action buttons.
- **About Me** — Personal introduction, interests, and development goals.
- **Skills Section** — Overview of technical skills and tools.
- **Projects Showcase** — Project cards with descriptions, technologies, and relevant links.
- **Experience & Education** — Internship experience and educational background.
- **Resume Section** — Access to my resume.
- **Contact Section** — Contact information and social profile links.
- **Responsive Design** — Layout adapted for mobile, tablet, and desktop screens.
- **Interactive UI** — Smooth scrolling, hover effects, and subtle animations.

*Features will be updated as they are implemented.*

## 🛠️ Technologies Used

- **HTML5** — Structures the website content using semantic elements.
- **CSS3** — Handles styling, layouts, responsive design, and animations.
- **JavaScript** — Adds interactive functionality and dynamic behavior.
- **Git & GitHub** — Used for version control and project hosting.
